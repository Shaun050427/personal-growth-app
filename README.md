# Personal Growth App

个人全方位成长系统的公开前端仓库。静态页面由 GitHub Pages 托管，私人数据不存放在本仓库。

部署方法见项目包根目录的 `README_部署说明.md`。

## 数据安全

- 不要向本仓库提交个人记录。
- 不要向本仓库提交 GitHub Token。
- 个人数据仅通过浏览器写入私有仓库 `personal-growth-data`。


## 成长决策功能

- **每周复盘**：首页和导航栏均可进入；周一至周日汇总科研推进、卡点、课程与日程计划、清单记录、训练、心法及成果。未来记录不计入实际推进，未记录与未勾选明确区分。
- **Markdown 导出**：先预览，再复制或下载给 ChatGPT；附有证据、项目取舍、最多三个下周重点及停止条件的分析提示。可排除训练，身体数据默认不纳入。没有模型 API 调用。
- **独立草稿**：复盘输入自动保存到当前浏览器，按周和数据仓库隔离；只有“确认保存复盘”才进入个人数据备份与云同步。选择历史周可查看、修改或删除已保存复盘。
- **项目评估**：中长期项目增加预期成果、工时和费用/算力预算、审查日期、奖励资格、基线差距、个人优势、可迁移价值、继续/终止条件和决策依据；新增“已终止”状态。到期项目在首页和复盘中提示，不自动终止。
- **参赛评估入口**：Kaggle / 天池日报的“评估是否参赛”预填项目名称、链接和奖励信息。仅保存后才创建项目，同一链接优先编辑已有项目；日报相关度不代表获奖概率。
- **成果资产**：记录报告、竞赛经验、代码、笔记和作品的日期、链接、证据与复用方式，可关联项目、搜索、筛选、编辑或删除。删除项目会解除成果关联，保留成果本身。

## 课程与学习：Canvas 快照接入

“课程库”扩展为课程详情、作业／考试、资料索引和实际学习记录；原有课程表保留。首页显示北京时间未来两周的待交作业、暂定考试和下一场考试，时间表单列本周截止事项。截止时间不自动占用学习时段，可从任务卡“安排准备时间”打开带课程与任务关联的日程草稿。

- **课程快照**：契约为 `canvas-sjtu-snapshot/v1`，包含 `source`、`timezone`、带时区的 `capturedAt`、课程、事项、资料。使用课程页专用入口，不能当作完整个人备份导入。来源链接仅接受交大 Canvas HTTPS 页面；日期、ID、引用、路径、文本长度与状态须通过验证。
- **导入预览**：按来源 ID 区分新增、更新与相同条目；确认前不写入。重复导入更新原记录，保留个人准备进度、备注、学习记录和目标关联；部分快照不删除缺失条目，旧快照不能覆盖较新版本。已核实课表可以选择合并，支持单双周及假期等例外日期。
- **私有数据**：课程快照放在用户配置的私有数据仓库 `data/canvas-sjtu-snapshot.json`。课程页“读取已保存的课程快照”复用现有 GitHub 读取能力，仍先预览再确认；不从公开前端分发真实课程、作业或成绩快照。原始课件不提交到公开仓库，索引记录文件名称、归档状态与 Canvas 入口。
- **不同状态**：个人做完、Canvas 已收到提交、教师已评分分别展示；个人勾选不修改平台事实。未交状态是最近采集时的观察，明确显示快照时间；未公布分数为未知，不填零分。暂定、推列和时间有误的事项保留确认程度。
- **真实学习**：记录学习／错题／实验／复盘／作品、实际日期、分钟数、输出、证据、卡点和下一步。周复盘排除未来学习记录和未来提交时间，课程计划与截止事项单列，不能算作已完成成果。
- **成果和目标**：课程可关联已有中长期项目；学习记录可主动收录成果快照，同一记录不重复收录。编辑或删除学习记录不改动已收录成果，删除项目只解除课程／成果关联。
- **备份与同步**：`academicCourses`、`academicItems`、`academicResources`、`academicRecords`、`academicImports` 为可选数组，参与原有备份、同步指纹及三方合并。缺失的新字段按空数组读取且不改变旧指纹；恢复旧备份会清空该版本没有的新字段。来源更新和个人修改分别保留。

本版没有启动 Canvas API 定时读取、提交作业、测验或发送消息。后续只读 API 采集器可输出相同快照契约，再进入已有预览／合并流程。

验证命令：`node --test tests/test_growth.js tests/test_academic.js tests/test_yi_integration.js`。自动化使用虚构课程与模拟 GitHub 响应，不读取或改写真实私人记录。

## 传统文化学习

- **入口与关系**：导航新增“传统文化”，承接本次阴阳、五行、干支、节气、《易》、河图洛书、罗盘、卜筮、六爻与三式的学习对话。长期目标在“中长期”，具体学习与实践在本模块，事实记录进入“每周复盘”，成熟输出主动收录“成果资产”，个人体悟先打开可编辑的“清风心法”草稿。
- **内置学习内容**：可搜索的18项概念释义、12周学习/实践/验收路线、一年深化方向、原文与现代阅读资料、第一堂90分钟课程、洛书与“十五”辨析、观察/决策/测量模板、六爻本卦与变卦练习器。学习周是单元，不按日历强制推进。
- **项目关联**：“建立 / 关联项目”可复用已有项目或创建预设目标；反复点击不重复创建。关联后可编辑目标、安排日程和查看成果。不自动写入私人记录或虚构已完成成果，也不增加每日清单。
- **学习记录**：概念卡、原文卡、实践卡、辨析卡支持新增、编辑、搜索、分类和删除。保存时记录实际日期、主题、学习单元、来源与解释边界；路线验收需要本人勾选。未来记录不计入本周实际进展。
- **成果与心法**：同一记录收录成果时复用既有条目，保留长期项目关联；成果是独立快照，后续可在成果库编辑。心法先由本人精炼确认；同一来源已有心法时直接查看。删除学习记录不会删除已收录成果，删除项目会解除记录关联。
- **数据与离线**：`cultureRecords`、`cultureProgress` 为新的可选数组，纳入备份、GitHub 同步及三方合并。旧备份缺少字段时读为空数组，不改变已有数据的同步指纹；恢复旧版本会清空该版本没有的学习记录。公开课程内容与私人记录分离，服务缓存包含两个新脚本。
- **验证范围**：自动化检查使用模拟页面元素和 GitHub 响应，覆盖初始化、关联、记录保存、重复收录、验收回退、旧数据恢复、报告日期筛选和动爻翻转；未进行真实浏览器的布局检查。

## 同步兼容与验证

继续使用原有 `personalPlanner_v2` 数据键与 V2 数据结构，`assets`、`weeklyReviews`、`cultureRecords`、`cultureProgress` 为可选数组。旧备份及旧云端数据缺少这些字段时按空数组读取；导入/历史恢复会正确清除不属于该版本的新记录，未知字段原样保留。

同步使用稳定字段顺序的指纹，旧同步元数据在首次启动时兼容迁移。保存已同步的数据快照作为三方合并基线，同一记录的独立字段、独立记录和清单勾选可以合并；覆盖同一字段、删除与编辑冲突或不兼容排序仍需明确选择。浏览器支持 Web Locks 时串行协调标签页上传；GitHub 文件 SHA 仍用于阻止过期写入。上传中发生的新编辑继续标记为未同步。遇到无法自动合并的内容，两边副本保存在本机并可一起下载。

升级后请关闭旧版本标签页，再重新打开网站，以免旧代码在其他标签页同步。独立复盘草稿只在当前浏览器保留，重要复盘请点击确认保存。

验证命令：

```sh
node --test tests/test_growth.js
python -m unittest discover -s tests -p 'test_*_report.py'
```

前端测试使用模拟的 GitHub 响应验证同步与保存逻辑，不读取或改写实际私人记录。

### Canvas API 同步

后台定时读取在私有 personal-growth-data 仓库运行，Canvas 凭据只保存在该仓库 Actions Secret。网页通过既有私有数据同步读取结果，不直接持有 Canvas 令牌。课程页显示最近成功同步、超过24小时未更新及部分权限受限提示，课程详情可展开最近90天公告摘要。人工核实的课表与暂定考试不因公告中的日期自动改变。新文件仅同步索引；原归档文件不能视为已下载最新版本。
